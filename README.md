# 图床小镇：简单可靠的图片外链工具

用一个轻量的免费图床，方便保存、分享和引用图片链接。

## 这是什么？

[图床小镇](https://imgbed.cn/) 是一个免费的图片托管服务（原敖武的图床）。如果外贸或电商产品图的外链容易失效，或者你需要一个稳定的 URL 与 Markdown 引用，可以试试从这里开始。请根据你的业务需求和服务条款使用。

## 快速开始

1. 打开 [https://imgbed.cn/](https://imgbed.cn/)。
2. 在页面中按 **Ctrl+V** 粘贴图片并上传。
3. 上传后复制 URL、Markdown 或 base64 内容，用于文档、店铺素材或页面引用。

## 功能概览

- 支持直接粘贴上传，减少文件选择步骤。
- 可复制 URL、base64 和 Markdown 格式。
- 支持照片、视频、ZIP、PDF 等文件，单文件约 100MB 以内（以网站当前提示为准）。
- 适合整理电商产品图、跨境业务素材和文档中的图片外链。
