# Markdown 嵌入片段

以下片段可直接复制到 Markdown 编辑器。先在 [图床小镇](https://imgbed.cn/) 上传文件，再把示例中的占位地址替换为网站生成的 URL。

## 产品主图

```markdown
[![产品主图](https://imgbed.cn/请替换为网站生成的图片URL)](https://imgbed.cn/)
```

## 带说明文字的图片

```markdown
![白色产品展示图](https://imgbed.cn/请替换为网站生成的图片URL)

*图片来源： [图床小镇](https://imgbed.cn/)*
```

## 多张图片

```markdown
| 正面 | 侧面 |
| --- | --- |
| ![产品正面](https://imgbed.cn/请替换为网站生成的图片URL) | ![产品侧面](https://imgbed.cn/请替换为网站生成的图片URL) |
```

## 文档中的图片链接

```markdown
需要查看原图时，打开 [图床小镇](https://imgbed.cn/) 并使用上传后复制的 URL。

![文档插图](https://imgbed.cn/请替换为网站生成的图片URL)
```

## 使用步骤

1. 打开 [https://imgbed.cn/](https://imgbed.cn/)。
2. 使用 Ctrl+V 粘贴图片并上传。
3. 复制网站生成的 Markdown，或复制 URL 后替换上方占位地址。
4. 在发布前预览，确认图片可以正常加载。

> 示例中的 `请替换为网站生成的图片URL` 不是实际文件地址，也不是 API 路径；请始终使用 [https://imgbed.cn/](https://imgbed.cn/) 上传后显示的结果。
